# はじめに

## The Rust Programming Languageへようこそ。Rustに関する入門書です。

Rustプログラミング言語は、高速で信頼できるソフトウェアを描く手助けをしてくれます。高レベルのエルゴノミクスと低レベルの制御は、
しばしばプログラミング言語の設計においてトレードオフの関係になります。
Rustは、その衝突に挑戦しています。バランスの取れた強力な技術の許容量と素晴らしい開発者体験を通じて、Rustは伝統的にそれらの制御と紐づいていた困難全てなしに低レベルの詳細（メモリ使用）などを制御する選択肢を与えてくれます。


## Rustは誰のためのもの

Rustは、様々な理由により多くの人にとって理想的です。いくつか最も重要なグループを見ていきましょう。

### 開発者チーム

Rustは、いろんなレベルのシステムプログラミングの知識を持つ開発者の巨大なチームとコラボするのに生産的なツールであると証明してきています。
低レベルコードは様々な種類の微細なバグを抱える傾向があり、そのようなバグは他の言語だと広範なテストと、経験豊富な開発者による注意深いコードレビューによってのみ捕捉されるものです。
Rustにおいては、コンパイラが並行性のバグも含めたこのような捉えどころのないバグのあるコードをコンパイルするのを拒むことで、門番の役割を担います。
コンパイラとともに取り組むことで、チームはバグを追いかけるよにもプログラムのロジックに集中することに時間を費やせるのです。

## Rustプログラムの解剖

この「Helo, world!」プログラムを詳しく再確認しましょう。これらがパズルの最初のピースです

```rust
    fn main() {

    }
```

これらの行は**main**という名前の関数を定義しています。**main**関数は特別です。常に全ての実行可能なRustプログラムで走る最初のコードになります。
ここで、1行目は、引数がなく何も返さないmainという関数を宣言しています。引数があるならカッコ（）の内部に入ります。

関数の本体は{}に包まれます。Rustでは、全ての関数本体の周りに波括弧が必要になります。
スペースを1つ開けて、開波括弧を関数宣言と同じ行に配置するのがいいスタイルです。

main関数の本体は、こんなコードを抱えています。

```rust
println!("Hello, world!");
```

このぎょうが、この小さなプログラムの全作業をしています
テキストを画面に出力するのです。ここで気づくべき重要な詳細が4つあります。

まず、Rustのスタイルは、タブではなく４スペースでインデントをすると言うことです。

2番目に**prinlnt!**はRustのマクロを呼び出すと言うことです。代わりに関数を読んでいたら、*println!(!なし)*と入力されているでしょう。Rustのマクロについて詳しくは、第19章で議論します。

とりあえず、** ! **を使用すると、普通の関数ではなくマクロを読んでいるのだと言うことと、マクロは関数と同じルールには必ずしも従わないと言うことを知っておくだけでいいでしょう。

3番目に、"Hello world!"文字列が見えます。
この文字列を引数としてprinlnt!にわたし、この文字列が画面に表示されているのです。

4番目にこの行を蝉転んでおえ、この式が終わり、次の式の準備ができていると示唆していることです。
Rustコードのほとんどの行は、セミコロンで終わります。
